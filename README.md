## 📋 Sobre o Projeto

Roteirize é uma plataforma web voltada para viajantes que buscam experiências autênticas e planejadas. O projeto oferece roteiros personalizados, dicas de viagem e relatos de experiências em destinos nacionais e internacionais.

## 🚀 Tecnologias Utilizadas

- **Nuxt 4** - Framework Vue.js com SSR
- **Vue 3** - Framework JavaScript progressivo
- **TypeScript** - Superset JavaScript com tipagem estática
- **Tailwind CSS 4** - Framework CSS utility-first
- **Nuxt Content** - Sistema de gerenciamento de conteúdo em Markdown
- **GitHub Actions** - CI/CD para automação de deploy

## ✨ Funcionalidades

- 🗺️ Sistema de roteiros de viagem personalizados
- 📝 Blog com relatos de viagens em Markdown
- 🔍 SEO otimizado para melhor indexação
- 📱 Design responsivo e mobile-first
- ⚡ Server-Side Rendering (SSR) para performance
- 🎨 Interface focada em UX e clareza visual
- 🚀 Deploy automatizado com CI/CD

## 🏗️ Arquitetura

O projeto segue boas práticas de desenvolvimento moderno:

- **Componentização** - Componentes reutilizáveis e escaláveis
- **Separação de responsabilidades** - Código organizado e manutenível
- **TypeScript** - Tipagem estática para maior segurança
- **SSR** - Melhor performance e SEO
- **Content-First** - Sistema de conteúdo baseado em Markdown

## 🎯 Diferenciais

- **UX centrada no usuário** - Navegação intuitiva e experiência fluida
- **Performance otimizada** - SSR e otimizações de bundle
- **SEO-friendly** - Meta tags, sitemap e estrutura semântica
- **Escalabilidade** - Arquitetura preparada para crescimento
- **Boas práticas** - Código limpo, versionamento e padrões modernos
